## 三、这一版发现的、任务书没提但影响判断的事

1. **"终身质保"是限时权益，不是条款。** C11 告知书通篇没有"终身质保"一节；它来自分批次的权益公告，且要"支付 5,000 元定金并最终提车"。**以 2026-11-11 计，该批次窗口（2026-07-31）已关闭。**
2. **服务数值不能跨车型搬。** 代步车上限 C11 = 200 元/天、A05 = 80 元/天。流传的 300 元/天在全部材料中无出处。
3. **门店类型决定能力。** 体验中心不能保养、不能保修；只有带"服务中心"的店能办首保与代步车。这条直接改变"附近有店"这个回答的价值。
4. **门店电话字段不稳定。** 同一门店销售热线在两个索引快照中不同（13106430644 / 13645754595），因此本库不给门店电话。
5. **官方页与配置库的质保表述差异是口径差异，不是真冲突。** 官方页只列首任车主权益行，配置库拆成"整车质保／三电质保／首任车主政策"三行，数值可并存。
