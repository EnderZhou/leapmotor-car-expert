## 在另一台电脑继续

```sh
git clone https://github.com/EnderZhou/leapmotor-car-expert.git
cd leapmotor-car-expert
```

已有克隆且工作区干净时，运行 `git pull --ff-only`。若有本地修改，先保留修改再拉取，避免覆盖。

安装 Python 3.10 或更新版本后，可从仓库根目录运行以下工程检查（仅使用标准库）：

```sh
python scripts/facts.py check
python scripts/facts.py selftest
python scripts/facts.py atest
python docs/evidence/reproduce-v0.5.3-checker.py
```
