# v0.2.0 资料缺口与变更清单

编制日期：2026-11-11。对应 v0.1.0 → v0.2.0 的开发阶段 A（盘点）与阶段 B（资料）产出。

## 一、本轮新增的核验能力

v0.1.0 记录的限制是“官方参数页读取不到正文，C11 数值主要依赖搜索索引”。本轮三次官方页读取（`leapmotor.cn/C10.html`、`/C11.html`、`/C16.html`）均返回了可引用的价格与功能栏目正文，因此：

- 三车系 17 个版本的全国指导价均有官方页与配置库记录，但**核对可复现程度不同**：C10 4 版与 C16 8 版为官方页可复现（L1）；C11 增程 2 版官方页读到过、独立复核未重现（L1\*）。v0.2.0 原表述“均由官方与配置库双向核对”过宽，已于 2026-11-11 修正，见 `docs/勘误记录-v0.2.0.md`。
- C11 由“仅纯电 640 三款”扩展为**纯电三款 + 增程两款**，补齐了 v0.1.0 明确排除在外的增程版本价格。
- `sources.json` 新增 `read_status` 字段，区分 `full-text`／`partial`／`shell-only`／`blocked`，避免把“只看到摘要”当成“已核实正文”。
- 汽车之家配置页直接抓取仍只返回页面框架（`shell-only`），配置数据来自搜索索引渲染的页面正文字段，已在来源条目中注明。
