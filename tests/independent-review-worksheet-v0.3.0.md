## 怎么填

对每一条：

1. 打开“来源链接”，看页面现在能不能读。
2. 找页面上有没有这条数值或说法，是否针对**同一版本**。
3. 页面是否写了限制（如“非全系标配”“以配置表为准”“指导价不含权益”）。
4. 在“复核判定”里选一项：`支持` ／ `不支持` ／ `无法读取` ／ `版本不明`。

判定标准：

- **支持**：页面明确写出该数值／说法，且版本一致。
- **不支持**：页面写了但数值或适用范围不同。
- **无法读取**：页面打不开、需登录、或只显示导航框架。
- **版本不明**：页面有该数据但看不出对应哪个年款／配置。
