3. **发现换行符问题**：本轮部分文件由 Python `write_text` 写入，在 Windows 上被写成 CRLF，与仓库其余文件的 LF 混在一起。`SHA256SUMS.txt` 因此被 `sha256sum -c` 判成"文件不存在"（报错里能看到 `'\r'`）。

   - 因为源码字节变了，**首轮三包全部作废并以 `--force` 重建**。首轮哈希：标准 `21be1ad9…610a`、技能 `4c4bfc56…b00f`、专家 `de3979ad…e190`，已覆盖、不保留。
4. 重建第二轮：标准包、技能包成功；**专家包首次失败**，报 `[WinError 32] 另一个程序正在使用此文件… .package-ps3czdys.zip -> leapmotor-car-expert-workbuddy.zip`（临时文件被占用，疑为杀软实时扫描）。等待 2 秒后重试同一命令，成功。上列哈希为**最终产物**。
