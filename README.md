# 零跑汽车专家

基于公开资料的零跑车型知识 Skill 与 WorkBuddy 专家。当前版本 **v0.5.3**，覆盖 C10、C11、C16 的 2027 款共 17 个版本（中国市场）。**本项目为独立社区项目，不代表零跑汽车官方服务或授权。**

## 下载与使用

在另一台电脑继续开发和测试，请先看 [v0.5.3 开发交接](docs/开发交接-v0.5.3.md)。当前客户端问答仍未验证；资料核对日期为 2026-11-11。

`packages/v0.5.3/` 下有三种包：

- `leapmotor-car-expert.zip`：标准 Agent Skill 包，入口为 `SKILL.md`。
- `leapmotor-car-expert-workbuddy-skill.zip`：WorkBuddy 技能格式，可通过技能上传入口导入。
- `leapmotor-car-expert-workbuddy.zip`：WorkBuddy 单专家包，内含技能、公开资料和原创头像。

校验值见 [SHA256SUMS.txt](SHA256SUMS.txt)，构建记录见 [package-validation-v0.5.3.txt](package-validation-v0.5.3.txt)。v0.1.0 至 v0.5.2 的历史包保留在原处，未被覆盖；**v0.5.1、v0.5.2 包已作废，请勿用于测试或分发**（原因见下表说明）。

## 能回答什么

- 查 17 个版本的价格、续航（CLTC／WLTC）、电池、功率、补能、尺寸、座位。
- 算差价：贵一万元买到哪些具体配置、五座六座差在哪、增程比纯电贵多少。
- **算落地成本**：含 2026—2027 年购置税减半（每辆乘用车**减税额**上限 1.5 万元，非实缴上限）的税额计算、保险与上牌待核项；**分期按付款时点分三栏**——① 此前已付（定金等）／② 提车当天尚需（首付余款＋当日税费保险上牌＋当日各方手续费）／③ 未来各期（月供×期数＋尾款）。截至提车累计自付＝①＋②；全期总支出＝①＋②＋③。**⑤「对贷款方累计付款」是另一个视角**（贷款方当日收取的费用＋③），不与 ②③ 相加；另设车价校验式 `①中车款＋②中首付余款＋贷款代付＝裸车成交价` 防重计。
- **按预算筛候选**：先问裸车还是落地、是否硬上限；超预算的车型只作标注差额的备选，不当合格推荐。**不把你的体验描述（"辅助驾驶好一点""空间大"）直接换成硬件或车系条件**——先问场景，确认后才加过滤，并说明因此去掉了哪几款。
- **判断补能是否可行**：家充四道门（车位／物业／电力／施工）、公共桩时间成本、长途补能估算。
- 解释辅助驾驶：硬件有什么、官方说支持什么、是否已交付——三层分开，不混为一谈。
- **讲质保与服务**（v0.5.0 新增，v0.5.1 修正）：基础质保（整车 4 年/12 万、三电 8 年/15 万，非营运与营运分开）与"终身质保权益"（限首任车主、限非营运、按批次公告发放）**分别核实**；C11 告知书先讲"未标版本与生效日期、元数据 2022-10"再给数值；首保、救援、代步车上限带车型给；权益期限拆成"现在还能不能领／已领到的还有效吗／持续享有什么条件"三问。C10、C16 条款文本本次未找到，会直说是缺口。
- 给试驾与订车清单：家庭成员实车验证、座椅与行李、同版本辅助驾驶试驾、合同与验车核对。
- 资料不足直说“未确认”，来源冲突并列展示并注明冲突类型。

## 数据来源与口径

17 个版本的价格按**来源级别**标注：

- **L1（15 个版本）**：零跑中国官方车型页可复现，且配置库数值一致（C10 4 版、C11 纯电 3 版、C16 8 版）。
- **L1\*（2 个版本）**：C11 增程两款。官方页读到过这两档价格，但另一人独立复核时只重现纯电三档。**原因是未确认的**，可能涉及缓存或 CDN、页面版本、请求参数、前端渲染方式，也可能其中一次提取不完整；现有材料没有响应体或截图，不足以定位原因。这两档另有配置库与第二来源支持，因此标 L1\*，**不能表述为“17 个版本均由官方双向核对”**。

级别只作用于价格。电池、芯片、续航等字段各有独立状态，不能继承价格的级别。

`sources.json` 共 **46 条**来源（去重后 45 个 URL），每条标 `read_status`（full-text 5／partial 40／blocked 1）与 `evidence_max`，并用 `covers{trims,fields,unsupported}` 声明适用范围，越界引用由程序拦截。**来源条数不等于独立证据数**：只有 5 条读到了可逐字引用的正文。

逐字段的事实记录在 `references/fact-records.json`（**261 条**，17 个版本），同时区分 `status`（值有多确定）与 `evidence`（材料多直接）；`confirmed` 但证据为 `indirect` 的有 43 条，如实标注不调高。配置矩阵与税表是它的派生视图，`check` 会拒绝过期视图。官方页面采集元数据与差异说明见 [证据文件](docs/evidence/2026-11-11-官方页面采集摘录.md)。

已知未确认字段与来源冲突逐项记录在各车型文档。v0.2.0、v0.3.0、v0.4.0 的记录错误已分别在 [勘误记录 v0.2.0](docs/勘误记录-v0.2.0.md)、[勘误记录 v0.4.0](docs/勘误记录-v0.4.0.md)、[勘误记录 v0.5.0](docs/勘误记录-v0.5.0.md) 中说明并修正。

## 覆盖范围与边界

已覆盖 C10 2027 款 4 版、C11 2027 款 5 版、C16 2027 款 8 版。**不是零跑全系数据库**，也不覆盖其他车系、其他年款、选装包完整清单与当前价格、车主手册、故障码与售后维修。

v0.5.0 起，质保与订车部分**部分补齐**：C11 的《车主基础服务权益告知书》与官方公告的《定购须知》拿到全文。但 **C10、C16 的告知书本次未找到**（按同名规则尝试 404，不能据此断定官方未公开），二者基础质保条款仍属未确认；**服务网点列表读不到**（页面脚本渲染，只拿到筛选控件）；**交付周期、辅助驾驶收费、常规保养价格、保险/上牌/贷款费率**无公开依据。这四类只能给核验清单与查询入口，不给条款、地址、时长与费用。

不读取零跑账号或实时车辆数据，不定位，不执行车控，不提供未经手册支持的菜单步骤、故障诊断或维修指令。不承诺交付时间、优惠幅度、OTA 时间表或辅助驾驶开通范围。

## 项目结构

- `source/leapmotor-car-expert/`：通用 Skill 源码与 **17 个**参考资料文件（含 `fact-records.json`、`sources.json`）。
- `packages/`：v0.1.0～v0.5.2 历史包（**其中 v0.5.1、v0.5.2 已作废，不得用于测试**）；`packages/v0.5.3/`：当前版本三包与构建报告。
- `scripts/facts.py`：事实记录校验、视图渲染与自测（`check`／`render`／`tax`／`selftest`／`atest`）；**不含任何产品数据**，数据只在 JSON 里。
- `test-cases.md`：80 题验收测试集（60 回归 + 20 购车场景）+ K 组 A01–A14 确定性反例。
- `tests/`：预期答案与资料审查、客户端实测清单、独立复核工作表、历史离线回归记录（已标注撤回）。
- `docs/`：资料缺口清单、勘误记录、交付摘要、官方页面采集摘录与原始提取件。
