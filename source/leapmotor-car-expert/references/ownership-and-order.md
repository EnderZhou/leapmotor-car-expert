# 质保、用车成本与订车交车

本页处理"买完之后"的问题。**质保条款、保养价格、服务网点、软件收费都没有本库可用的完整数据**，所以这里给的是核实路径与提问清单，不是条款结论。

## 一、质保：五件事必须分开问

配置库只记录到"整车四年或 12 万公里；首任车主终身质保（非营运），责任免除条款以官方为准"。这一句不够用。逐项问官方：

1. **范围**：整车质保 vs 三电（电池／电机／电控）质保，是否分开计算。
2. **是否限首任车主**：过户后是否降为普通质保，降成几年。
3. **是否限非营运**：跑网约车、租赁是否失效。
4. **维持条件**：是否要求在官方渠道保养、是否限制事故维修渠道、是否要求每年回店检查。
5. **电池衰减**：是否有衰减到某比例才免费更换的条款，检测方法与判定主体是谁。

规则：**不得把"终身质保"说成"所有零件免费换"**，也不得承诺电池衰减到多少就换新。以官方当期条款为准，条款页面要用户自己核对。

## 二、用车成本：只算能算的

能算的：

```
年电费 = 年里程 × 百公里电耗 ÷ 100 × 电价（区分家充谷电与公共快充）
年油费 = 年里程 × 亏电油耗 ÷ 100 × 油价（增程车，按用户实际用电比例折算）
```

本库可用的能耗数据：C10 纯电百公里 13.8 kWh、增程 18.2 kWh；C11 纯电 14.4 kWh、增程 19.1 kWh；C16 增程 19.7 kWh。这些是**工况值**，实际高于此。

不能算的：保险（需报价）、保养（需报价）、维修、折旧、残值。**不预测保值率，不给"三年后能卖多少钱"。**

回答成本问题时，必须把输入逐项列出：年里程、家充占比、电价、油价、油耗口径。缺输入就给公式，不给结论。

## 三、软件与流量

- 车机基础流量、娱乐流量、辅助驾驶功能是否收费、是否订阅制——**本库未确认**。
- 不得从硬件（有没有激光雷达、有没有 8650）推断"功能免费"或"功能要订阅"。
- 只能列为到店确认项：问清免费期限、续费价格、功能是否随账号绑定、二手车主能否继承。

## 四、服务网点

需要用户自愿提供的城市或区县。无联网检索时：

- 给官方渠道入口（官网服务页、官方 App 内的服务地图、客服电话），不臆造地址与营业时间。
- 不索取精确住址、不索取车辆定位。
- 不承诺配件到货时间、维修时长、代步车。

## 五、订车与交车核验清单

签合同前：

- [ ] 书面报价单：裸车价、选装、税费、保险、上牌、贷款费用逐项列出（口头不算）
- [ ] 交付版本写清：车系、年款、动力、配置等级、座位数、内外饰颜色
- [ ] 交付时间写成具体日期或"不超过 X 周"，并写明逾期责任
- [ ] 定金／订金性质与退款条件写进合同（"定金"与"订金"法律含义不同）
- [ ] 补贴与权益写进合同：金额、到账方式、到账时间、未到账怎么办
- [ ] 贷款方案：总支出、期数、提前还款违约金

交车时：

- [ ] 车辆铭牌与合格证上的年款、配置与合同一致
- [ ] 里程、生产日期、轮胎生产周次
- [ ] 外观漆面、玻璃、轮毂
- [ ] 随车物品：充电桩权益凭证、随车工具、说明书
- [ ] 车机版本与已开通功能当场确认
- [ ] 发票金额与合同一致（影响购置税与后续权益）

## 六、边界

- 不替销售做承诺，不判断合同是否合法有效，不解释退款权利——建议咨询官方客服或法律专业人士。
- 不预测降价、改款时间、保值率。
- 没有当期官方条款时，不给质保结论。
