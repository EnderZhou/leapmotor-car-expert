# 口径术语表

同一个词在不同来源里含义不同，回答时必须先声明口径。以下为本站资料的固定用法。

## 价格类

| 术语 | 含义 | 注意 |
|---|---|---|
| 全国指导价 | 厂商公布的官方指导价 | 本站默认价格口径；不含补贴、优惠、上牌与保险 |
| 经销商报价 | 某门店挂牌价或优惠后价 | 单店单时点，易变，不得写成全国行情 |
| 落地价 | 含购置税、保险、上牌等的预估总支出 | 第三方估算，非官方；不要与指导价混用 |
| 限时权益 | 上市期或活动期的选装基金、充电桩、金融贴息等 | 必须带活动起止日期；过期即失效 |
| 平台补贴 | 第三方平台的补贴 | 非厂商政策，随时变动 |

## 续航与补能类

| 术语 | 含义 | 注意 |
|---|---|---|
| CLTC | 中国轻型汽车行驶工况的标称续航 | 偏理想，通常高于实际；不换算成“真实续航” |
| WLTC | 全球统一轻型车测试循环 | 数值通常低于 CLTC；两口径不可混用 |
| 综合续航 | 增程车型满油满电的标称总续航 | 必须说明是 CLTC 还是 WLTC |
| 纯电续航 | 增程车型仅用电可行驶的标称里程 | 与综合续航区分 |
| 30–80% 快充 | 电量区间补能时间 | 与“充满时间”不同；受桩功率与温度影响 |
| 800V 平台 | 高压架构，支持更高充电功率 | 不代表任何桩都能跑满峰值 |
| 热泵空调 | 用热泵制热以降低冬季电耗 | 与 PTC 制热不同；并非所有车型都有 |

## 配置与版本类

| 术语 | 含义 | 注意 |
|---|---|---|
| 标配 | 该版本出厂即含 | 需官方配置表确认，宣传页不等于标配清单 |
| 选装 | 需额外付费或选装包内提供 | 说清选装包名称与价格，以及是否限时抵扣 |
| 版本限定 | 仅某配置提供，如激光雷达智尊版的后排屏、冰箱 | 不得泛化为车系通用 |
| 计划功能／待 OTA | 官方称将通过软件更新提供 | 不等于当前已可用；须标注交付状态 |
| 智享版 | 基础配置等级（C10、C11） | 通常不含激光雷达 |
| 尊享版 | 基础配置等级（C16） | 与 C10／C11 的“智享版”不是同一命名体系 |
| 激光雷达版 | 增加激光雷达与高阶辅助驾驶硬件的等级 | 硬件在≠功能全开，功能受软件与地区限制 |
| 激光雷达智尊版 | 激光雷达版之上的高配 | 常叠加后排屏、冰箱、大轮圈、音响等 |
| 增程 | 以电驱动、以内燃机发电补充 | 与“插电混动”不同，增程器不直接驱动车轮（本站资料范围内不展开技术细节） |
| 纯电 | 仅电力驱动 | — |

## 证据类

| 术语 | 含义 |
|---|---|
| 未确认 | 本次来源未提供该字段，或无法判断哪个值正确 |
| 来源冲突 | 同一版本同一字段出现不一致数值，且无法用版本或口径解释 |
| 待核验 | 有单一来源或间接支持，但不足以作为结论 |
| 媒体口径 | 来自媒体整理或实测，非官方参数表 |
| 资料快照 | 截至某一日期的公开资料状态，不随页面变化自动更新 |
