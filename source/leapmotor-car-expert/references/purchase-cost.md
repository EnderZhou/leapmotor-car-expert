# 落地成本与报价拆解

核对日期：2026-11-11。本页只给计算方法与规则；**没有一个数字是某地某店的真实报价**。

## 一、先分清三种"钱"

| 说法 | 含义 | 用法 |
|---|---|---|
| 指导价 | 厂商公布的全国统一价（本库口径） | 只能当起点，不是成交价 |
| 成交价／裸车价 | 门店实际开票价（可能含优惠） | 用户提供或门店报价才有，本库无此数据 |
| 落地价 | 裸车 + 购置税 + 保险 + 上牌/服务费 + 选装 + 贷款费用 − 补贴 | 决策真正要比的数 |

**不得把指导价当落地价，也不得假设"新能源免购置税"。** 2026 年的规则变了。

## 二、购置税：2026—2027 是减半，不是免征

依据财政部、税务总局、工信部《关于延续和优化新能源汽车车辆购置税减免政策的公告》（2023 年第 10 号）：

- 购置日期在 **2026-01-01 至 2027-12-31** 的新能源汽车，**减半征收**车辆购置税，每辆新能源乘用车减税额**不超过 1.5 万元**。
- 购置日期按**机动车销售统一发票开具日期**确定。
- 车型须列入《减免车辆购置税的新能源汽车车型目录》才可享受。
- 纯电、插电式混合动力（含增程式）、燃料电池汽车属于新能源汽车。

计算式：

```
不含税价 = 含税车价 ÷ 1.13        （按 13% 增值税率折算）
应纳税额 = 不含税价 × 10%
实缴税额 = min(应纳税额 ÷ 2, 1.5 万元)
```

## 三、落地账单模板

逐项填写，缺一项就标"待报价"，**不得静默填零**。

| 项目 | 金额（万元） | 来源／状态 |
|---|---:|---|
| 裸车成交价 | | 门店书面报价；无则填指导价并注明 |
| 选装 | | 用户选了才计；未核实价格标待报价 |
| 购置税 | | 按上表或公式算，注明按指导价还是成交价 |
| 交强险 | | 按座位数与使用性质确定的基准保费 + 浮动，需保险公司出单 |
| 商业险 | | 需报价；与车价、险种、地区、驾龄相关 |
| 上牌／服务费 | | 地区差异大，需门店明示 |
| 贷款手续费／GPS／续保押金 | | 需门店明示，常见于分期方案 |
| 贷款利息总额 | | 见下节计算式 |
| 补贴（厂家／地方／置换） | | **不预先扣减**，见第五节 |
| **合计** | | 以上各项相加 |

## 四、贷款：比总支出，不比月供

两种方案月供接近但总支出可能差几千元。必须取齐五个数：

首付、期数、每期月供、尾款（如有）、手续费／服务费。

```
总支出 = 首付 + 月供 × 期数 + 尾款 + 手续费 + 利息（若月供已含利息则不重复加）
```

若门店只给"月供"，先要总支出；给不出就标"无法比较"。

## 五、补贴：资格、时点、到账方式三件事

- **资格**：厂家补贴常限指定版本或库存车；地方补贴限本地开票、本地牌照；置换补贴要求旧车过户与持有期。
- **时点**：多数为限时活动，本库记录的 C16 权益（2026-06-16 至 07-31）、C10/C11 选装基金半价均为**已过期**政策，只能作为"历史上存在过"的参考，不能进当前报价。
- **到账**：有的直接抵扣车价，有的先付后返（数月），有的以充电额度／积分形式发放。先付后返的不减少当期现金支出。
- **叠加**：厂家 + 地方 + 置换能否同享，需逐项问清，不做默认假设。

规则：**未确认资格与到账方式的补贴，一律不扣减，只列为"可能减项"。**

## 六、回答预算问题的硬规则

1. 先问清是**裸车预算**还是**落地预算**，以及是否为**硬上限**。
2. 落地预算换算裸车上限时，必须扣掉购置税、保险、上牌，且这些多为未确认项 → 只能给"裸车需控制在约 X 万以内"的区间，不能断言"落地一定不超过 Y 万"。
3. 候选车指导价超过已确认预算的，**不得列为合格推荐**；只有用户明确愿意加预算时，才作为备选并写明差额与超支比例。
4. 不得以"可能有优惠""可能有补贴"来让超预算车型"看起来能买"。

## 七、示例：落地 14 万能不能买 C16

C16 增程 280 尊享版五座指导价 14.58 万，已超 14 万落地预算的裸车上限，且购置税约 0.645 万、保险上牌另计，落地明显高于 14 万。结论：**不合格**，需向用户说明差额，或改看 C10 290 智享版（12.58 万，购置税约 0.557 万，落地在 13.5 万上下，具体以保险与上牌报价为准）。

注意"13.5 万上下"仍带假设（保险与上牌未确认），须一并说明。
