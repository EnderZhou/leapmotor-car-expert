# 零跑汽车专家 Skill｜0.1.0 原型

基于公开网页资料的非官方车型知识助手。首版样板资料：C10、C11、C16；不是全系数据库。

## 使用范围

车型与配置查询、版本比较、按需求整理候选、公开功能解读、有限口碑线索。知识事实和回答规则位于 `references/`，来源索引位于 `references/sources.json`。

不提供手册操作步骤、维修排障、实时车况读取或车控。涉及价格、权益、软件状态时须现场核实；未现场核验则明示资料日期。

## 发布状态

当前为可审阅的初版源码与客户端适配包。C11 阅读入口采用维护者确认可在中国访问的 `https://www.leapmotor.com/C11.html`；中国区数值交叉核对另列 `.cn` 动态参数页。网页读取工具与中国境内用户浏览器呈现可能不同，域名／地区／动态渲染差异尚未被独立确认。回答具体配置时仍须核对用户所在地区与适用配置表。WorkBuddy 元数据标注本 GitHub 维护者 EnderZhou。未在 WorkBuddy 客户端实测导入／召唤，不能视为已上架或官方授权产品。
