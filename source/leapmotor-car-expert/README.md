# 零跑汽车专家 Skill｜0.2.0

基于公开网页资料的非官方车型知识助手。已整理 C10、C11、C16 的 2027 款共 17 个版本；不是零跑全系数据库。

## 使用范围

车型与配置查询、年款与版本比较、按需求整理候选、公开功能解读、有限口碑线索。

- 回答规则与工作流程：`SKILL.md`
- 车型资料：`references/model-c10.md`、`model-c11.md`、`model-c16.md`、`model-index.md`
- 六类场景的回答骨架：`references/answer-patterns.md`
- 口径术语（指导价／CLTC／WLTC／标配／选装等）：`references/glossary.md`
- 来源索引与读取状态：`references/sources.json`
- 引用与冲突处理规则：`references/source-policy.md`

不提供手册操作步骤、维修排障、实时车况读取、定位或车控。涉及价格、权益、软件状态时须现场核实；未现场核验则明示资料日期。

## 资料状态

17 个版本的全国指导价已由零跑中国官方车型页与汽车之家配置库双向核对（核对日期 2026-11-11）。仍存在未确认字段与来源冲突，逐项记录在各车型资料的“未确认字段”与“来源冲突记录”中，回答时须如实披露，不得补值。

`sources.json` 的 `read_status` 区分本轮实际读取深度：`full-text`／`partial`／`shell-only`／`blocked`。汽车之家配置页直接抓取只返回页面框架，配置字段来自搜索索引渲染的正文，已在对应来源注明。
